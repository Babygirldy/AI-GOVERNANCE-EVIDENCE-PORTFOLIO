## Worked example: Govern, Map, Measure, Manage

- **GOVERN:** Name the senior owner, approve policy and define accountability.
- **MAP:** Identify candidates affected, intended use, system boundaries, harms and data flows.
- **MEASURE:** Test ranking errors, disparate impacts and control effectiveness with documented methods.
- **MANAGE:** Delay deployment, implement controls, assign remediation and reassess risk.

This example is **teaching material**. The learner should recreate it with one sentence explaining **why** each action fits its function.

## Tutor's first prompt
**R-04:** If a supplier boasts '90% accurate hiring recommendations', what questions must you ask before concluding the tool is safe and fair?

**Guided reasoning:** 'Accuracy' needs a definition, representative validation groups, false-negative rates, job-by-job tests, fair comparisons, and clarity about the actual decision consequences. A single headline percentage is not adequate assurance.

**Your task:** Summarise this reasoning in two or three original sentences before moving to R-05.
